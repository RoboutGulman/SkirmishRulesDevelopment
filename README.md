# Gang Showdown — Разработка книг правил скирмиш-варгейма

[![Build and Release Rulebooks](https://github.com/RoboutGulman/SkirmishRulesDevelopment/actions/workflows/build-and-release.yml/badge.svg)](https://github.com/RoboutGulman/SkirmishRulesDevelopment/actions/workflows/build-and-release.yml)
[![GitHub release](https://img.shields.io/github/v/release/RoboutGulman/SkirmishRulesDevelopment?include_prereleases&color=8a1414)](https://github.com/RoboutGulman/SkirmishRulesDevelopment/releases)
[![Typst](https://img.shields.io/badge/typeset%20with-Typst-239dad.svg)](https://typst.app/)

Проект верстки и параллельной разработки трех книг правил для тактического скирмиш-варгейма **Gang Showdown 1.4** (адаптация и ребаланс правил Necromunda).

В качестве инструмента оформления используется **Typst** — современная система верстки, компилирующая документ в PDF за доли секунды и идеально оптимизированная для совместной работы человека и AI-агента (**Google Antigravity**).

## 📥 Где взять готовые PDF-файлы

Вы можете получить скомпилированные книги правил двумя способами:

### 1. Скачать с GitHub (рекомендуется)
Каждый официальный выпуск автоматически собирается и публикуется в разделе релизов:
👉 **[Перейти к загрузкам: GitHub Releases](https://github.com/RoboutGulman/SkirmishRulesDevelopment/releases)**

Там всегда доступны свежие версии трех файлов:
- **`Gang_Showdown_01_Core_Rules.pdf`** — Книга 1: Основные правила (структура раунда, действия, стрельба, ближний бой, урон, быстрая памятка игрока).
- **`Gang_Showdown_02_Gang_Creation.pdf`** — Книга 2: Создание банды и Арсенал (правила найма на 1000 кредитов, карточки и матрица навыков Дома Голиаф, базовое, тяжелое, рукопашное оружие, броня и экипировка).
- **`Gang_Showdown_03_Campaign_Rules.pdf`** — Книга 3: Правила кампании и Сценарии (кампания Доминиона, послематчевая фаза, таблица травм D66, территории, механика андердога, сценарии 1–4).

### 2. Собрать локально на компьютере
После запуска локальной сборки готовые файлы будут находиться в папке:
📂 **`release/`** в корне репозитория.

## 🗂 Структура репозитория

Проект спроектирован по модульному принципу: все повторяющиеся стили и компоненты вынесены в общее ядро, а каждая книга изолирована в собственной папке.

```text
SkirmishRulesDevelopment/
├── common/                          # Общая переиспользуемая библиотека
│   ├── template.typ                 # Базовый шаблон (поля A4, шрифты, колонтитулы, цвета)
│   └── components.typ               # Компоненты (карточки бойцов, таблицы оружия, D66, плашки)
│
├── books/                           # Исходники трех книг
│   ├── 01_core_rules/               # КНИГА 1: ОСНОВНЫЕ ПРАВИЛА
│   │   ├── main.typ                 # Точка входа книги 1
│   │   ├── build.bat                # Скрипт сборки книги 1
│   │   └── chapters/                # Главы (введение, действия, бой, памятка)
│   │
│   ├── 02_gang_creation/            # КНИГА 2: СОЗДАНИЕ БАНДЫ И АРСЕНАЛ
│   │   ├── main.typ                 # Точка входа книги 2
│   │   ├── build.bat                # Скрипт сборки книги 2
│   │   └── chapters/                # Главы (лимиты, Голиафы, оружие, броня)
│   │
│   └── 03_campaign_rules/           # КНИГА 3: ПРАВИЛА КАМПАНИИ И СЦЕНАРИИ
│       ├── main.typ                 # Точка входа книги 3
│       ├── build.bat                # Скрипт сборки книги 3
│       └── chapters/                # Главы (структура кампании, D66 травмы, территории, миссии)
│
├── release/                         # Папка для готовых скомпилированных PDF
├── .github/workflows/               # Автоматизация GitHub Actions (CI/CD)
│   └── build-and-release.yml        # Автосборка и прикрепление PDF к релизам
│
├── build_all.bat                    # Сборка ВСЕХ трех книг одной командой
└── README.md                        # Документация проекта
```

## 🚀 Быстрый старт: Локальная сборка

### Шаг 1: Установка Typst
Typst поставляется как компактный одиночный бинарный файл без внешних зависимостей.
- **Windows (через Winget):**
  ```powershell
  winget install --id Typst.Typst
  ```
- **macOS (через Homebrew):**
  ```bash
  brew install typst
  ```
- **Linux:**
  ```bash
  cargo install --locked typst-cli
  ```
- Или скачайте готовый архив со страницы [Typst Releases](https://github.com/typst/typst/releases) и добавьте `typst.exe` в системный `PATH`.

### Шаг 2: Компиляция всех книг
В корне репозитория дважды кликните или выполните в терминале:
```cmd
build_all.bat
```
Скрипт автоматически найдет компилятор Typst, создаст папку `release/` и скомпилирует все 3 книги правил менее чем за 1 секунду.

### Шаг 3: Сборка отдельной книги
Если вы редактируете конкретную книгу, перейдите в ее папку и запустите локальный `build.bat`:
```cmd
cd books\01_core_rules
build.bat
```
Или выполните стандартную команду Typst из корня репозитория:
```bash
typst compile --root . books/01_core_rules/main.typ release/Gang_Showdown_01_Core_Rules.pdf
```

## 🎨 Переиспользуемые компоненты (`common/components.typ`)

Все визуальные элементы унифицированы и доступны для использования в любой главе:

### 1. Карточка характеристик бойца (`fighter-card`)
```typst
#fighter-card(
  name: "Тиран (Forge Tyrant)",
  title-suffix: "Лидер банды",
  cost: "130 кредитов",
  stats: (m: "4\"", ws: "3+", bs: "3+", s: "4", t: "4", w: "2", i: "4+", a: "3", ld: "5+", cl: "5+", wil: "7+", int: "7+"),
  equipment: ("Боевой тесак", "Бронежилет"),
  skills: ("Bullcharge", "Nerves of Steel"),
  rules: ("Активация группы: до 2 бойцов в 4\".",)
)
```

### 2. Таблица профилей оружия (`weapon-table`)
Стандартная таблица с 10 столбцами (дистанция, точность, сила, пробитие брони, урон, проверка патронов, спецправила, цена, доступность).
```typst
#weapon-table(
  category: "Базовое оружие",
  items: (
    (name: "Автоган", rng-s: "8\"", rng-l: "24\"", acc-s: "+1", acc-l: "-", str: "3", ap: "-", d: "1", am: "4+", traits: "Rapid Fire (1)", cost: "15 кр.", rarity: "О"),
  )
)
```

### 3. Таблица брони и снаряжения (`wargear-table`)
```typst
#wargear-table(
  category: "Броня",
  items: (
    (name: "Бронежилет (Flak)", cost: "10 кр.", rarity: "О", effect: "Спас-бросок 6+ (5+ против взрывов)."),
  )
)
```

### 4. Таблица бросков D66 (`d66-table`)
```typst
#d66-table(
  title: "Таблица травм D66",
  items: (
    (roll: "11", name: "Мгновенная смерть", effect: "Боец погиб. Вычеркните из ростера."),
    (roll: "66", name: "Выживший", effect: "Полное здоровье и +D3 XP."),
  )
)
```

### 5. Выноска / Плашка правил (`callout`)
```typst
#callout(title: "Важное правило")[
  Текст особого правила или авторского комментария.
]
```

## 🤖 Редактирование с помощью Antigravity

Благодаря модульности и чистому синтаксису Typst, разработку очень удобно вести совместно с **Antigravity**.

Примеры запросов для агента:
- *"Добавь в Книгу 2 главу с правилами для Дома Эшер: ростер, карточки Лидера и Матриарха, яды и матрицу навыков."*
- *"Создай в Книге 3 сценарий с эвакуацией ценного груза на вагонетке."*
- *"Обнови таблицу тяжелого оружия в trading_post_weapons.typ, добавив Лазпушку и Мультимельту."*

## 💻 Редактирование в VS Code (Живой предпросмотр)

Для максимально удобной работы в Visual Studio Code:
1. Установите расширение **Tinymist Typst** (рекомендуется автоматически при открытии папки).
2. Откройте любой файл `.typ` и нажмите сочетание клавиш `Ctrl + K, V` (или кнопку предпросмотра в правом верхнем углу).
3. При каждом сохранении файла страница предпросмотра обновляется мгновенно прямо в окне редактора.
